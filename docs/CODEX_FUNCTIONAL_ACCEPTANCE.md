# Codex functional acceptance ledger

Goal: one approved PRD becomes a graph of node-sized tasks, one Codex exec session and Git worktree per task, independently reviewed, then one tested delivery. This is a functional orchestration plugin, not a hardened hostile-worker OS confinement product. Trust the operator's explicitly disposable repositories, conventional Codex workspace sandbox, and Mycelink's deterministic graph, TDD, evidence and SHA gates. No permission bypass, hidden profile credential copies, automatic push or network setup.
