# Quickstart control repository

The Mycelink control repository of the quickstart. It registers two
independent Git repositories, `../orders-api` and `../orders-web`, and holds
feature ORD-101: its approved PRD, acceptance manifest, contract and
portfolio graph. Feature state, evidence and candidates are written here
as the feature runs; product code never is.

See `examples/quickstart/README.md` in the Mycelink repository.
